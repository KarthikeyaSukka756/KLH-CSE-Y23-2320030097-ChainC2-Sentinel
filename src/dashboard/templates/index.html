Research Synthesis & Observations

Authoritative research findings, scenario differentiation, methodological boundaries, and report downloads.

Core Research Question & Differentiating Logic
"Can cross-layer telemetry correlation detect blockchain-mediated C2-like behavioral sequences while distinguishing them from legitimate Web3 activity?"
Scenario A — Benign Web3
Standard JSON-RPC eth_blockNumber & balance polling. No suspicious smart contract state, no dead-drop, no network egress.
Score: 10 / 80 ➔ No Detection
Scenario C — Legitimate DApp
Complex multi-contract interactions, Uniswap/ERC-20 transfers. Legitimate contracts, no C2 instructions, no beacon egress.
Score: 35 / 80 ➔ No Detection
Scenario B — Synthetic C2
Complete correlated sequence: Process context → RPC call → Dead-drop retrieval → C2 command parsing → Matched network egress.
Score: 100 / 80 ➔ Detection Triggered
Phase 1 — Detection Findings

Cross-layer correlation successfully prevented false alarms on normal Web3 and complex DApp traffic by requiring both blockchain-mediated command indicators and subsequent network egress.

Phase 2 — Defensive Response Findings

Controlled mitigation demonstrated 100% RPC blocking and beacon containment on confirmed C2 activity, while preserving 100% of legitimate Web3 and DApp transactions with zero false mitigations.
